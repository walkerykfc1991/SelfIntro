# Walker Yip — personal introduction

A single-page introduction for Walker Yip, taken from the approved CV. It is a personal introduction only. It is not a job board and it does not take work requests.

## Preview locally

There is no build step and no server to install. From this folder, open `index.html` in a browser.

To preview through a local address instead:

```bash
python3 -m http.server 8080
```

Then open http://localhost:8080

## This repository

The repository is currently private. GitHub Pages is not enabled here. A private repository would not give a public introduction page.

If the repository is later made public, GitHub Pages can serve `index.html` and `styles.css` from the repository root on the default branch. That setting is left for the owner to turn on. `.nojekyll` is included so Pages can serve these files directly.

## Files

- `index.html` — the page
- `styles.css` — layout, including a print style
- `favicon.svg` — typographic mark (initials only; there is no portrait)

The name on the page is Walker Yip. Email is the contact link. Employment wording, skills, and education follow the CV and are not extended with extra tools, employers, or profile links.
